# 拍照讲题：运行、隐私与验收边界

## 1. 功能定位

拍照讲题是学生练习中心的桌面端辅助工具，不是题库第六种正式训练模式，也不会把学生上传的题目并入公共题库。当前闭环为：

`上传一张 408 题图 -> AI 识别 -> 学生核对并确认 -> 选择讲解深度 -> 私有保存 -> 跳转到已核验知识点或关联练习`

AI 只负责识别和讲解。客观判分、错题、掌握度、FSRS 复习时间、学习证据和任务完成状态均由确定性服务管理；拍照讲题的识别、确认、讲解和保存不会写入这些学习状态。

当前仅支持网页桌面端，不提供手机拍照页或移动端适配承诺。

## 2. 输入和配额

| 项目 | 当前限制 |
| --- | --- |
| 单次文件 | 只能上传 1 张图片 |
| 支持格式 | PNG、JPEG、WebP；声明类型必须与真实格式一致 |
| 上传大小 | 原始上传和规范化后的 WebP 均不超过 5 MiB |
| 解码像素 | 不超过 20,000,000 像素 |
| 归一化结果 | WebP，最长边不超过 2,048 像素，移除原始 EXIF 等元数据 |
| 临时题目 | 未保存记录保留 24 小时；每个学生最多 10 条有效临时记录 |
| 私有保存 | 每个学生最多 100 条、图片总量最多 250 MiB |
| 讲解深度 | 只给方向、分步讲解、完整解析 |

“只给方向”和“分步讲解”必须返回空的最终答案字段；模型若泄露最终答案、返回未知知识点 ID 或不符合结构契约，服务端会拒绝整份结果。

## 3. 身份和数据隔离

- 所有接口都从服务端会话读取学生身份，不接受浏览器传入 `user_id`。
- 只有已分配至少一门 408 课程的学生可以使用；教师、管理员和未登录请求不能借此读取学生题目。
- 查询、确认、讲解、保存、图片读取和删除均按当前账户校验所有权。跨账户访问统一返回未找到，不暴露资源是否存在。
- 浏览器 DTO 不返回私有文件名、文件哈希、磁盘路径、提示词、原始模型输出或幂等存储内容。
- 图片接口要求登录，响应使用 `Cache-Control: private, no-store` 和 `X-Content-Type-Options: nosniff`。

## 4. 图片存储与外发边界

服务端先在本地用 Sharp 解码、旋转、缩放并重新编码为 WebP，再以随机 UUID 文件名写入私有目录。数据库只保存受约束的文件引用和元数据，不保存图片字节。

默认目录为 API 包内被 Git 忽略的 `outputs/external-questions/`。生产或试点环境建议显式配置独立私有目录：

```dotenv
EXTERNAL_QUESTION_STORAGE_DIR=D:\xuetu-private\external-questions
```

该目录不能位于 `apps/web/public`，也不能覆盖 API 应用目录；Web 服务器不得把它配置为静态资源目录。

使用当前 OpenAI-compatible 中转时，隐私口径必须准确：

- 识别阶段会把归一化后的题图发送给配置的外部中转；因此不能宣称“题图从不离开校内主机”。
- 请求不包含平台账户 ID、私有磁盘路径、API 密钥、标准答案或其他学习证据。
- 学生确认后，讲解阶段只发送确认后的题目文本和至多 8 个服务端白名单知识点，不再发送图片。
- 是否允许真实学生题图经过该中转，需要在正式试点前完成告知、授权和提供方数据留存核验；未完成时只使用合成题图演示。

## 5. 中转配置

拍照讲题复用现有服务端 `LLM_*` 配置和熔断器，浏览器不直连中转。模型保持为当前约定的 `gpt-5.6-terra`：

```dotenv
LLM_BASE_URL=https://<relay-host>/v1
LLM_API_KEY=<server-only-key>
LLM_MODEL=gpt-5.6-terra
LLM_TIMEOUT_MS=30000
```

真实密钥只放在被忽略的 `apps/api/.env.local`，不得提交、写入本文档、发到浏览器或出现在截图和日志中。远程地址应使用 HTTPS。

中转不可用时，上传记录仍按私有生命周期保存，页面显示可重试失败；系统不会用演示答案冒充真实识别，也不会因此修改任何学习状态。

识别重试和讲解请求会先按 `Idempotency-Key` 查询已完成结果，顺序重试不会再次调用中转。数据库事务采用“先锁定用户或题目，再检查幂等记录”，因此并发请求不会重复写入题目状态或讲解版本。当前尚未实现跨请求的分布式 AI 单飞：两个完全同时到达、且尚无已完成记录的相同 AI 请求仍可能都到达中转并产生调用费用，但最终只接受一份数据库结果；桌面端会在请求期间禁用对应操作以降低该概率。

讲解保存同时校验学生确认内容的版本。若学生在讲解生成期间从另一标签页修订题干或已核验知识点关联，旧讲解会被拒绝，必须基于最新版本重新生成。

## 6. 删除、过期和清理

- 用户删除后，题目立即被标记为已删除，后续列表、详情和图片读取均不可见。
- API 会立即尝试删除对应私有图片并完成清理标记；文件删除失败时释放清理占用，交给后续批次重试。
- 每次清理领取的租约为 10 分钟；若 API 在物理删图前异常退出，租约过期后该记录可由后续批次重新领取，不会永久卡在清理中。
- API 启动时执行一个最多 20 条的清理批次；每次成功创建上传记录后也会异步触发清理。
- 未保存且超过 24 小时的记录会从学生列表排除，并进入图片清理队列。
- 当前删除是“立即禁止访问 + 物理图片清理 + 数据库软删除审计”，不是数据库行的即时硬删除。若正式制度要求在固定期限后彻底清除审计行，需要另行实现并审批数据库保留策略。

备份必须同时覆盖 PostgreSQL 和 `EXTERNAL_QUESTION_STORAGE_DIR`。只备份数据库会丢失原图，只备份文件目录会丢失归属和生命周期信息；恢复时两者应来自同一备份时间点，且私有目录权限不得放宽。

## 7. 主要失败码

| 类别 | 失败码 | 含义 |
| --- | --- | --- |
| 图片 | `IMAGE_TYPE_UNSUPPORTED` / `IMAGE_TYPE_MISMATCH` | 格式不支持，或声明格式与真实格式不一致 |
| 图片 | `IMAGE_INVALID` / `IMAGE_TOO_LARGE` / `IMAGE_PIXEL_LIMIT` | 图片损坏、文件过大或解码像素超限 |
| 状态 | `EXTERNAL_QUESTION_EXPIRED` / `EXTERNAL_QUESTION_INVALID_STATE` | 临时题目已过期，或操作顺序不合法 |
| 配额 | `EXTERNAL_QUESTION_TEMPORARY_LIMIT` / `EXTERNAL_QUESTION_SAVED_LIMIT` / `EXTERNAL_QUESTION_SAVED_BYTES_LIMIT` | 临时数量、保存数量或保存容量达到上限 |
| AI | `UPSTREAM_UNAVAILABLE` / `WORKFLOW_TIMEOUT` | 中转不可用或请求超时，可按响应的 `retryable` 决定是否重试 |
| AI | `RECOGNITION_INVALID_RESPONSE` / `EXPLANATION_INVALID_RESPONSE` | 模型输出未通过严格契约或白名单校验 |
| 幂等 | `IDEMPOTENCY_KEY_REQUIRED` / `EXTERNAL_QUESTION_IDEMPOTENCY_CONFLICT` | 缺少幂等键，或同一键被用于不同请求 |

## 8. 可复跑验收

### 确定性端到端测试

端到端测试只模拟外部 AI 边界，认证、PostgreSQL、私有图片、权限和学习状态走真实路径：

```powershell
$env:PLAYWRIGHT_API_PORT="3194"
$env:PLAYWRIGHT_WEB_PORT="5394"
$env:PHOTO_TUTOR_FIXTURE_PORT="8394"
pnpm exec playwright test -c e2e/playwright.config.ts e2e/photo-question-tutor.spec.ts
```

测试会生成合成 408 题图，并验证 1440x900、1280x900 两档页面无横向溢出、导航不遮挡内容、按钮文字不裁切、私有图片可解码且非空白、页面不暴露内部字段，以及讲解前后学习记录完全不变。

### 真实中转抽样

先使用忽略的本地配置启动 API，再在另一终端运行：

```powershell
$env:PORT="3312"
pnpm --filter @xuetu/api start

$env:SMOKE_API_ORIGIN="http://127.0.0.1:3312"
pnpm --filter @xuetu/api external-question:smoke
```

脚本只上传合成题图，依次执行识别、确认和“只给方向”，检查请求模型与上游自报模型一致、方向层没有最终答案、学习记录未变化，并在结束时删除临时题目。输出不得包含密钥、Base64、完整请求、题目私有路径或学生隐私信息。

一次 smoke 成功只能证明本次调用通过，不能证明中转长期稳定，也不能独立证明提供方实际加载的底层权重。

## 9. 对外表述禁止项

不得宣称：

- 已训练、微调或部署 Qwen3.8 27B；当前路线已撤下。
- 中转模型是本项目自研模型，或上游自报模型 ID 等同于底层权重证明。
- AI 识题和讲题始终正确，或无需学生核对识别结果。
- 上传题图在使用外部中转时完全不离开本地或校内网络。
- 拍照讲题会自动更新错题、掌握度、FSRS、学习证据或今日任务。
- 学生上传题目会自动进入公共题库，或关联知识点来自未经核验的模型猜测。
- 当前功能已经证明提分、降低备考压力、提高留存率或提升上岸率。

演示时可准确表述为：系统把学生自有 408 题目转成“可核对、分层讲解、私有保存、关联校内已核验知识点”的一次辅助学习过程；AI 失败不会污染确定性学习记录。

# 讲义原文页

四本教材的 OCR 文本存在字母混淆、分数线和上下标丢失。学生阅读器通过 `source_page` 显示对应 PDF 原页，原始 OCR 数据保留，未进行猜测性公式替换。

## 生成

在仓库根目录运行 `python scripts/build-course-reading-pages.py --os-pdf <计算机操作系统第4版原始PDF路径>`。需要 PyMuPDF 和 Pillow。其余原文件取自上级工作目录的 `课程资料`。脚本按源 PDF SHA-256 复用已有页图，核对插图清单中的页码偏移，生成 180dpi 无损 WebP，并在全部完成后原子替换 `manifest.json`。

映射规则：数据结构印刷页 +14；操作系统 +9；计网上册 +11，下册 -239（印刷页240起）。组成原理正文 +7，前置目录与内容提要仍用原导入的物理页。跨页图示引用不能用作正文起始页。

当前覆盖：数据结构406页、操作系统407页、计网474页、组成原理427页，共1714页，对应1791个原始文本片段。API当前开放的896个知识片段均已检查到对应原页。

## 运行

API默认读取此目录，可通过 `COURSE_READING_PAGES_PATH` 指定完整目录。`processed/` 页图被现有 `.gitignore` 排除，需要与清单一起保留；仅拷贝代码或清单不会带上原页资源。本次仅供现有本地环境使用。

原页接口复用学生身份与课程成员检查；只允许读取清单中对应课程的页 ID，图片字节需通过 SHA-256 校验，缓存为 private。页图缺失或损坏时显示重试，不把损坏的 OCR 自动重新放回正文。

网页原文保持整页比例，可放大至200%。来源翻页使用知识点已有的来源引用，不把原书印刷页直接当作导入记录偏移。旧段落书签按同样数量的纵向区域映射到原页，保存近似阅读位置；不表示该页公式已做语义校对。

本次修复原文阅读显示。OCR原始文字、AI检索输入和原书数学内容本身没有被自动重写。

# 测试数据目录

这里存放智算智伴本地联调使用的数据副本。完整语料不作为应用源码，也不应直接提交到代码仓库。

## 目录约定

- `data-structures/raw/`：另一组交付的原始文章，只读保留。
- `data-structures/processed/`：切块、分类等派生结果，可重新生成。
- `data-structures/samples/`：可进入自动化测试的小规模、可审查样本。
- `data-structures/manifest.json`：文件规模、校验值、质量检查和已知问题。

## 使用边界

当前语料主要来自 CSDN，适合验证导入、检索、引用展示和接口联调，不等于最终比赛知识库。正式版本应优先使用课程教材、教师讲义、实验指导书和经过授权的权威材料，并保留可追溯来源。

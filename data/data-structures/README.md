# 数据结构测试语料

## 数据流

1. `raw/articles.jsonl` 是原始文章主档，共 165 条。字段为 `id`、`text`、`metadata`。
2. `processed/chunks.jsonl` 是检索候选主档，共 1449 条。字段为 `id`、`document_id`、`text`、`metadata`。
3. `processed/by-topic.json` 是 12 个知识主题的展示索引，共 1448 条文本。
4. `samples/` 用于放置经过筛选的小型联调样本。

后端检索和引用链路应以 `chunks.jsonl` 为准，通过 `document_id` 回溯 `articles.jsonl`。`by-topic.json` 缺少稳定 ID 和来源元数据，只适合知识目录、数量统计或人工浏览，不应作为检索事实源。

## 当前质量检查

- 165 条原文和 1449 条切块均可逐行解析。
- 原文 ID、切块 ID 均无重复。
- 文本均非空。
- 1449 条切块均能通过 `document_id` 找到原文。
- 分类版比切块版少 1 条，而且文本经过加工，无法可靠地按全文反向连接切块。

## 使用限制

这批数据用于开发测试。来源权威性、版权授权、内容正确性和去重情况尚未完成正式验收，不能直接作为比赛答辩中的“权威知识库”依据。

# 计算机类院校复试线本地数据

本目录整理用户提供的 `院校复试信息.xlsx`。原始工作簿复制保存在
`raw/院校复试信息.xlsx`，由 `.gitignore` 排除；规范化 JSON 保存在
`processed/retest-lines.normalized.json`，同样不进入源码版本控制。

## 已核验范围

- 2024—2026 年，共 3,374 条学校/学院/专业层面的复试线记录。
- 覆盖 446 所学校、971 个学校—培养单位组合、65 个非空专业代码。
- 原始表中 3,316 条记录来自路灯考研公开分数线库，其余记录来自院校、科研机构或其他公开页面。
- 3,374 个复试线来源 URL 均为合法 HTTPS URL；未发现完全重复的数据行。
- 记录可用于院校目标筛选和复试线趋势参考，不能代表最终录取结果。

## 数据边界

- 当前数据只有复试线/进入复试范围信息，不含拟录取名单、最终录取结果和复录比。
- 不得据此计算或宣称个人录取概率、院校上岸率或平台提分效果。
- 第三方汇总与历年信息可能过期，面向学生展示时必须提示以目标院校当年官方公告为准。
- `license_status=unverified`
- `usage_scope=local_demo_only`
- `training_allowed=false`

## 目录

- `manifest.json`：来源、哈希、核验数量与使用边界。
- `raw/院校复试信息.xlsx`：原始工作簿副本，保留不改。
- `processed/retest-lines.normalized.json`：规范化记录，供后续数据库导入或接口设计使用。

本批仅整理数据源，没有导入 PostgreSQL，也没有新增学生端院校推荐页面。
